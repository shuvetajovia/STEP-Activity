ACTIVITY 4: Testing the Enhanced Account Class

Objective
Write a test class that verifies all the new features using boolean return values.

Requirements
Create a test class TestAccountEnhanced.java that tests:

1. Valid account creation
2. Invalid age (under 18) - should auto-correct to 18
3. Invalid account type - should default to "Savings"
4. Minimum balance enforcement on creation - should auto-correct
5. Minimum balance enforcement on withdrawal - should return false
6. Account status management (close and reopen)
7. PIN protection (set, verify, correct/incorrect PIN)
